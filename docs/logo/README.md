# igvano logo

| File | Use |
|---|---|
| `igvano-horizontal.svg` / `.png` | Mascot and wordmark side by side, light backgrounds |
| `igvano-horizontal-dark.svg` / `.png` | Same, dark backgrounds |
| `igvano-stacked.svg` / `.png` | Mascot above wordmark, light backgrounds |
| `igvano-stacked-dark.svg` / `.png` | Same, dark backgrounds |
| `igvano-mark.svg` / `.png` | Mascot and container only, no wordmark |
| `igvano-icon.svg` / `.png` | Square icon |

All files have a transparent background except the icon. The wordmark is
converted to outlines, so no font is needed to render it.
